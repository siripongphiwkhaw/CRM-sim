B2C SKU Mapping

How a B2C sale from D2C, Shopee, Lazada or TikTok is mapped from the SKU the channel sends to a B2C SKU, its brand and its Business Unit (BU). Below: the structure, a mapping diagram, the five mapping steps, nine sample transactions you can click through, and an example dashboard.

Structure

The SKU master is kept once; each sales transaction line points into it. B2C SKUs are never linked to B2B products.

Mapping steps at import

Run for every B2C order line, in this order. A step that fails sends the line or SKU to the to-fix list; the line still loads.

1

Find the listing

Channel + SKU on the line → channel listing. A new SKU becomes a new listing.

2

Find the B2C SKU

Same code → automatic. Legacy code → admin mapping.

No link: UNKNOWN_CHANNEL_SKU

3

Read the variant

Suffix → base SKU, variant, pack quantity. _C2 = promo, 2 units.

4

Find the brand

CDP brand code of the SKU, else of its base SKU.

B2C_NO_BRAND · B2C_UNKNOWN_BRAND

5

Save the BU

Brand → BU on the order date, saved on the line with the brand used.
