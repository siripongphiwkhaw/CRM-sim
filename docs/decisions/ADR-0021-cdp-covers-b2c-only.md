# ADR-0021 — CDP ครอบคลุมเฉพาะ B2C ส่วน B2B อยู่ที่ SAP ทั้งหมด

**สถานะ:** Accepted
**แก้ไขข้อความใน:** ADR-0002, ADR-0012

## ข้อเท็จจริง

- **CDP (Fabric) มีข้อมูลเฉพาะฝั่ง B2C** ฝั่ง B2B ไม่มีข้อมูลอยู่ใน CDP เลย
- **ฝั่ง B2B อยู่ที่ SAP ทั้งหมด**

## ทำไมข้อนี้สำคัญ

ADR-0002 ตัดสินว่าไม่ต้องสร้าง Activity Master ใน CRM Phase 1 โดยอ้างเหตุผลหลักว่า
**"ไม่มีข้อมูลใดสูญหาย เพราะ Fabric เก็บ raw event ไว้ให้อยู่แล้ว"**

ข้อความนั้นเขียนกว้างเกินไป มันจริงเฉพาะฝั่ง B2C ส่วนฝั่ง B2B ระบบที่ทำหน้าที่นี้
คือ SAP ไม่ใช่ CDP

## Decision

ยืนตาม ADR-0002 และ ADR-0007 ตามเดิม **แต่แก้เหตุผลให้ตรงกับความเป็นจริงของแต่ละฝั่ง**

| ฝั่ง | ระบบที่ถือข้อมูลอยู่วันนี้ | เหตุผลที่ไม่ต้องสร้างใน CRM Phase 1 |
|---|---|---|
| **B2C** | CDP (Fabric) | ข้อมูลไม่สูญหาย CDP เก็บ raw event ให้อยู่แล้ว |
| **B2B** | SAP | ข้อมูลอยู่ที่ SAP ครบ และในขอบเขต Phase 1 ยังไม่มีงานใดต้องใช้ |

ไม่มีฝั่งใดที่ข้อมูลตกหล่นโดยไม่มีเจ้าของ ซึ่งเป็นเงื่อนไขที่ทำให้ ADR-0002
ยังปลอดภัยอยู่

## สิ่งที่ต้องยืนยันกับทีม SAP

คำว่า "อยู่ที่ SAP ทั้งหมด" ครอบคลุมข้อมูลสองชนิดที่ระบบ ERP โดยทั่วไป
**ไม่ได้ออกแบบมาให้เก็บ** จึงควรยืนยันเป็นรายข้อ ไม่ใช่สันนิษฐาน:

1. **ความยินยอม PDPA พร้อมหลักฐาน** — ผู้ติดต่อฝั่ง B2B เป็นบุคคลธรรมดา
   จึงอยู่ใต้ PDPA เช่นเดียวกับผู้บริโภค ADR-0017 กำหนดให้ migrate consent เดิม
   โดยต้องได้ทั้ง *สถานะ* และ *หลักฐาน* (ใครยินยอม เมื่อไหร่ ช่องทางไหน
   ข้อความเวอร์ชันไหน) ถ้า SAP เก็บเพียงสถานะ จะได้มาไม่ครบตามที่ ADR-0017 ต้องการ
2. **ประวัติการติดต่อสัมพันธ์** — ERP มักถือข้อมูลนิติบุคคล ธุรกรรม และเครดิต
   แต่ไม่ถือบันทึกการโทรหรือการพบลูกค้า ถ้า SAP ไม่ได้เก็บส่วนนี้ ก็ตรงกับ
   ADR-0006 ที่ระบุว่าชั้นนี้เป็นของ CRM อยู่แล้ว และตรงกับ ADR-0011 ที่ให้ CRM
   เป็นเจ้าของชั้นความสัมพันธ์ — ไม่ใช่ปัญหา แต่ต้องรู้ว่าเริ่มจากศูนย์

**ถ้าคำตอบคือ SAP ไม่ได้เก็บสองข้อนี้** ผลคือ consent ฝั่ง B2B ต้องเก็บใหม่จากลูกค้า
ไม่ใช่ยกมาจากระบบเดิม ซึ่งเป็นงานของฝ่ายขาย ไม่ใช่งานไอที และต้องนับเป็น effort
ของฝั่งธุรกิจในแผน

## ผลต่อ ADR อื่น

- **ADR-0002** — เหตุผล "ไม่มีข้อมูลสูญหาย" ต้องอ่านคู่กับตารางข้างบน
  ฝั่ง B2C คือ CDP ฝั่ง B2B คือ SAP
- **ADR-0012** — ข้อความ "ข้อมูลทั้งหมดจาก CDP ผ่าน consent แล้ว" ครอบคลุมเฉพาะ B2C
  ส่วน consent ฝั่ง B2B ต้องมาจาก SAP ตามข้อที่ต้องยืนยันข้างบน
- **ADR-0018** — ยืนยันว่าต้นทาง migration สองระบบครอบคลุมครบทั้งสองฝั่งจริง
