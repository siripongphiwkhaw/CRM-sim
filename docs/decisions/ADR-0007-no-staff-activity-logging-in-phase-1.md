# ADR-0007 — CRM Phase 1 ไม่รวมการบันทึก staff activity

**สถานะ:** Accepted
**เกี่ยวข้อง:** ADR-0001 (sequencing mandate), ADR-0006 (ความเป็นเจ้าของ 3 ชั้น)

## Context

ADR-0006 สรุปว่า **staff-generated activity** (บันทึกการโทร, การเข้าพบ, โน้ต,
การติดต่อในเคส, งานติดตาม) เป็นข้อมูลที่ CRM ต้องเป็นเจ้าของ เพราะไม่มีระบบอื่น
ในองค์กรถืออยู่ — Fabric CDP ให้ไม่ได้เพราะข้อมูลนี้ไม่ได้เกิดในช่องทางดิจิทัล
ที่ Fabric ไป ingest และ SAP ก็ให้ไม่ได้เพราะอยู่คนละฝั่ง (B2B)

คำถามที่ตามมาคือ **แล้วต้องทำใน Phase 1 เลยหรือไม่**

ข้อเสนอที่ถูกปฏิเสธคือให้ทำใน Phase 1 โดยเพิ่มประเภทกิจกรรมของพนักงาน
แยกจากประเภทเชิงพฤติกรรม เหตุผลที่เสนอคือข้อมูลชั้นนี้ไม่มีใครเก็บแทนได้

## Decision

**Phase 1 เก็บเฉพาะ Customer Master ตาม mandate — ไม่รวมการบันทึก staff activity**
การบันทึกกิจกรรมของพนักงานเลื่อนไป phase ถัดไป

ADR-0006 ยังคงมีผลในฐานะ **หลักการความเป็นเจ้าของ** — เมื่อถึงเวลาสร้าง
ข้อมูลชั้นนี้ต้องอยู่ที่ CRM ไม่ใช่ที่อื่น ADR นี้กำหนดเพียง *จังหวะเวลา* ไม่ได้
เปลี่ยนว่าใครเป็นเจ้าของ

## Consequences

**ผลดี**

- Phase 1 มีขอบเขตเดียวชัดเจน ตรงกับ mandate "Customer Data First" แบบไม่มีข้อโต้แย้ง
- ไม่มีอะไรมาแย่ง timeline ซึ่งเป็นข้อจำกัดจริงข้อหนึ่งของ Phase 1
- ตัดการถกเรื่องประเภทกิจกรรมออกจาก Phase 1 ทั้งหมด ซึ่งเป็นหัวข้อที่ต้องใช้
  input จากทีมหน้างานจริงและจะยืด requirement phase ออกไป

**ความเสี่ยงที่ยอมรับอย่างรู้ตัว**

- **ข้อมูล staff activity ช่วง Phase 1 จะไม่มีการเก็บ และกู้ย้อนหลังไม่ได้**
  จุดนี้ต่างจาก ADR-0002 โดยสิ้นเชิง — ADR-0002 ปลอดภัยเพราะ Fabric เก็บ
  behavioral event ให้อยู่แล้ว แต่ **ชั้น staff activity ไม่มีระบบใดเก็บสำรองไว้เลย**
  ถ้าไม่เก็บ ข้อมูลนั้นจะไม่เคยมีอยู่
- ผลกระทบจริงของความเสี่ยงนี้ขึ้นกับว่า Phase 1 มีโมดูล service/case หรือไม่ —
  ถ้ามี โมดูลนั้นจะทำงานได้ไม่เต็มรูปเพราะไม่มีประวัติการติดต่อประกอบ
  **(คำถามค้าง — ต้องเคลียร์กับขอบเขตตาม RFP)**

**เงื่อนไขที่ทำให้ต้องทบทวน**

- ถ้าขอบเขต Phase 1 ตาม RFP รวมงาน service/case หรือ sales follow-up ไว้ด้วย
  ต้องกลับมาพิจารณาใหม่ เพราะโมดูลเหล่านั้นใช้งานจริงไม่ได้ถ้าไม่มี activity
